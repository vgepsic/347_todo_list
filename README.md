# Todo list

Web app simple écrite avec utilisant Node.js + sqlite.

## Installation des dépendances

1. Node v24
2. Autre dépendances à installer avec la commande :
   ```
   yarn install  --production
   ```

## Exécution
1. Exécuter l'app avec la commande :
   ```
   node src/index.js
   ```
2. Consulter l'app @ `http://127.0.0.1:3000`
